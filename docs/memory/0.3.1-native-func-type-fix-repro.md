# native/func-type-fix: reproduced native miscompile of func_type's `Type | error` return

## Symptom (gen2 native-built, aborts native-building gen3)
The checker fails at item 0 emitting ~25 diagnostics, EACH with an EMPTY message and a
garbage position `1439897514:21845` (col `21845` = `0x5555`, the top bytes of a PIE/heap
pointer under `setarch -R`):
```
  checker    0/7075 items   2.4s  ✗  src/build/project.tks:1439897514:21845:
teko: .: src/build/project.tks:1439897514:21845:
src/checker/escape.tks:1439897514:21845:
src/checker/typer.tks:1439897514:21845:
src/codegen/codegen.tks:1439897514:21845:
...
```
The pinned M.1 "out of memory (str concat)" (exit 134) is the SAME defect with a huge
garbage message length; this run's payload bytes gave an empty/short length, so it fell
through to exit 1 instead of the malloc abort. Same by-address corruption either way.

## The path
`collect_fn_signature(item, f, table, env)` (src/checker/collect.tks:303):
```
match func_type(f, table, item.namespace) {
    Type as t => ...define_fn...
    error as e => SigOutcome { ...; diags = one_diag(located_diag(item.file, f.line, f.col, e)) }
}
```
The `file` field of each diagnostic is CORRECT (it is `item.file`, collect's own arg, not
from the error). But `located_diag` (diagnostics.tks:37) takes line/col/message FROM the
error `e`:
```
let line = if inner.line != 0 { inner.line } else { decl_line }   // inner.line = 1439897514 (garbage, nonzero)
let col  = if inner.line != 0 { inner.col }  else { decl_col }     // inner.col  = 21845 = 0x5555
diag_at(file, line, col, inner.message)                            // inner.message = garbage str
```
So `func_type` returns a value whose union tag reads as `error` and whose payload
(line/col/message) is garbage — a by-address corruption of the `Type | error` return.
The C route accepts the same source, so this is NOT a legitimate signature failure.

## STATUS: reproduced; root-cause instrumentation next.
Candidate: `func_type` (collect.tks:80) builds `params: []Type` / `param_names: []str` /
`defaults: []parser::Expr` by self-append push inside a loop, then returns
`Func { params; ret; ...; param_names; n_required; defaults }` as `Type | error`. The
`Type | error` aggregate union return is read by-address at the `collect_fn_signature`
match; a slice member conveyed through a reclaimed region would corrupt the union tag/payload.
Same family as 5026006a (region-lifetime) / 74622f77 (free-old) — to be pinned by
instrumenting the actual faulting value before the fix.
